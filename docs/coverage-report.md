## How to update

1. Add or refresh a file in `data/registry/` with the list's source URL, retrieval date, and how it was collected.
2. Run `npm run registry:report`. It rewrites this report and `supabase/registry-entries.sql`.
3. Load the SQL into the database. Entries needing review appear in the review queue at `/registry-review` for admins.
4. Adding an institution to the catalog still requires verifying it against an official source; a registry entry alone is not enough.
